Signal Dataset is a structured research corpus built from the public Telegram channel [WallstreetQueenOfficial](https://t.me/WallstreetQueenOfficial). It contains raw channel posts scraped day-by-day, alongside LLM-extracted JSON signals — each with entry range, targets, stop-loss, and direction — ready to feed a backtesting or calibration pipeline.

## What's in the dataset

| Metric | Value |
|---|---|
| Raw channel posts | 9,189 |
| LLM-extracted signals | 921 |
| Long signals | 521 |
| Short signals | 294 |
| Wait / non-signal verdicts | 106 |
| USDT symbols with full 1m-candle coverage | 82 |
| Date range | 7 May 2021 – 30 Sep 2026 |
| Monthly folders | 65 |

## How it works

<Steps>
  <Step title="Scrape">
    `scripts/fetch_messages.mjs` pulls every post from the Telegram channel day-by-day into per-month `messages.jsonl` files using `telegram-reader`.
  </Step>
  <Step title="Filter">
    Each month's `generate-signals.mjs` applies a keyword pre-filter — keeping only posts that contain both an entry keyword (`entry`, `buy zone`, `market price`, …) and a levels keyword (`target`, `take profit`, `stop`) — and extracts candidate tickers from hashtags.
  </Step>
  <Step title="Extract">
    For each (post, ticker) pair that passes the filter, the script calls an Ollama LLM (`gemma4:31b-cloud`) with a period-specific Mustache prompt and records the structured JSON verdict in `signals.jsonl`.
  </Step>
  <Step title="Backtest">
    The structured signals feed a downstream `backtest-kit` project that opens 24-hour positions, records per-minute PnL trajectories, and calibrates exit thresholds against the trajectory population.
  </Step>
</Steps>
